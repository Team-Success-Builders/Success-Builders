# Team Success Builders – BIOSA / AMEU site

**`index.html` is the finished site.** Styles, scripts and photos are built into it, so it works
by itself – double-click it, host it on GitHub Pages, or open it from any file manager.

Upload `index.html` to the root of your GitHub repo, then Settings → Pages → Deploy from branch (`main`, root).

## Editing
`source/` holds the same site split into `index.html`, `style.css`, `script.js` and `images/`.
Quick text edits (names, roles) can be made directly in `index.html`: search for the person's name.
- Martee's role: change `Team Member` in the last Team card.
- WhatsApp group link: `WA_LINK` in the script, and the `href` of the "Open WhatsApp group" button.

## Form
WhatsApp group links can't take pre-filled text, so the message is copied and the group opens for the student to paste and send.
